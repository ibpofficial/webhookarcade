# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Webhook Arcade team takes the security of webhook capture, cryptographic signature handling, and SSRF prevention seriously.

If you believe you have discovered a security vulnerability in Webhook Arcade, please do **NOT** open a public issue.

Instead, please send a detailed vulnerability report via email to **security@webhookarcade.dev** (or submit a private security advisory on GitHub).

### What to Include
1. Description of the vulnerability and potential impact.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. The specific component affected (e.g. `packages/replay-engine` SSRF validator, `apps/api` ingest parser).
4. Suggested mitigation or fix, if known.

We aim to acknowledge all reports within 48 hours and provide a remediation timeline within 7 business days.
